Pagination

Numbered navigation across pages of content.

Default

Shows the first and last page, the current page ±1, and ellipses across the gaps.

Component

total sets the page count; uncontrolled via defaultPage, or pass page + onPageChange to control it.

Component

Seed with data-total and data-page; app.js (initPagination) renders and wires the rest. 

<nav class="pagination" data-pagination data-total="12" data-page="1" aria-label="Pagination"></nav>

JavaScript

From app.js. Renders the windowed page list and re-renders in place on click, keeping focus on the pressed control.
