File Upload

A dashed dropzone around a native file input; click or drop to pick.

Default

The whole box is the <label>, so a click anywhere opens the picker and native drag-and-drop works with no JS. The hidden input keeps the focus ring via :focus-within.

Multiple, no hint

Drop the hint line for a compact zone. multiple accepts a set; accept filters the picker.

Component

title is the prompt, hint an optional second line, buttonLabel the Browse button; the wrapping label names the input. Other props (accept, multiple, disabled, onChange) pass through.

Component

<label class="file-upload">
  <input type="file" class="file-upload__input" />
  <svg class="file-upload__icon" aria-hidden="true">…</svg>
  <span class="file-upload__title">Drop a file here or browse</span>
  <span class="file-upload__hint">PNG or JPG, up to 5 MB</span>
</label>
