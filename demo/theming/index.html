Theming

A few anchors feed derived roles; components read only the roles. Change an anchor and everything downstream retints.

The three layers

Every color resolves through this chain. You style at the top; the rest follows.

1. Anchors

The source of truth. One neutral plus brand and status hues, as raw channel triples (--anchor-neutral, --anchor-primary, …).

2. Roles

Derived by color-mix and alpha: surfaces, ink, borders, the --accent family. Each carries hover/active. Dark mode swaps these, not the components.

3. Components

Read roles only (var(--accent), var(--ink-primary)). They never see an anchor, so they retint for free.

Anchors

The whole palette derives from these. --anchor-neutral alone drives grays, ink, fills, borders, and shadows.

--anchor-neutralgrays, ink, fills, shadows
--anchor-primarybrand accent
--anchor-reddestructive, error
--anchor-greensuccess
--anchor-blueinfo
--anchor-amberwarning
--background-secondarycard / sheet surface

Contextual accent (data-color)

Wrap any region in data-color and every accent-aware component inside retints from that one context. Same markup, three skins. This is the payoff of the layer system.

data-color="primary" Active
data-color="neutral" Active
data-color="red" Active

Three contexts ship: primary (brand), neutral (muted), and red (destructive). Button, Badge, Chip, and Alert consume the accent. Semantic colors (success, warning, error) stay fixed by meaning and do not follow the region.

Dark mode

Dark is a role swap, not a second set of components. Toggle the theme in the top nav to see this whole page flip. Text on solid fills stays legible automatically: --accent-on picks black or white from the fill's own lightness. 

/* Components never branch on theme. They read one role: */
.button--primary {
  background: var(--accent);
  color: var(--accent-on); /* auto black/white */
}
/* [data-theme="dark"] redefines the roles once, globally. */

Rebranding (one knob)

As the designer you set this once; you will rarely touch it after. Changing a single anchor re-derives the entire system, both themes, every component. Shown for understanding, not day-to-day use. 

:root {
  --anchor-primary: 108 43 245;  /* brand hue → every accent */
  --anchor-neutral: 40 40 40;    /* grays/ink → tint the whole UI */
}
/* Nudge --anchor-neutral toward a hue (e.g. 38 40 52) and every
   gray, border, and shadow warms or cools with it. */
