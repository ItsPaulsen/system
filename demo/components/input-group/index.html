Input Group

An input with addons — an icon, short text, or a button beside the field.

Icon

An SVG in the input__leading (or input__trailing) slot. The slot shares the field's focus ring, and the icon is decorative (aria-hidden) — the label names the field. --rounded gives the pill search field.

Text

Short text addons — a unit, prefix, or suffix (e.g. $, USD). Both slots can be used at once.

Button

Put a button--flat Button in a slot (size it with data-size="sm") for an inline action like copy or clear. It picks up the right padding and sits flush to the field edge automatically.

Markup

<span class="input__container">
  <span class="input__leading"><svg …>…</svg></span>
  <input class="input__element" type="text" />
  <span class="input__trailing" data-size="sm">
    <button class="button button--flat">Copy</button>
  </span>
</span>
