Accordion

Collapsible sections built on native <details>.

Default

Native <details>: open and close work with no JavaScript.

How do I get started?

Import the tokens, then reference them with var(--…).

Can I change the colors?

Swap the anchor values in globals.css and everything retints.

Does it support dark mode?

Yes, set data-theme="dark" on the root.

Component

Compound components over native <details>. The toggle icon is baked into the trigger; styling is the same .accordion classes.

Component

<div class="accordion">
  <details class="accordion__item">
    <summary class="accordion__summary">
      Question
      <span class="accordion__toggle">…</span>
    </summary>
    <div class="accordion__body"><p>Answer.</p></div>
  </details>
</div>
