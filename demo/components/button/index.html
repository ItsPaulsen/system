Size

Set data-size on any ancestor.

Primary

Flat

Destructive

Colors

Wrap any ancestor in data-color (primary, neutral, red, green, blue); the accent skins retint from that one context. Destructive stays red.

Icon-only

Always pair with aria-label.

With icon

Tightens the padding on the icon side.

Disabled

Loading

A spinner replaces the label while the button keeps its width. Use aria-disabled + aria-busy (not disabled, which grays it out).

Component

The typed <Button> the snippets use. Emits the same classes; needs globals.css + components.css.
