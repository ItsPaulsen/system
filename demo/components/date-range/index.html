Date range

Two months for choosing a start and end date.

Default

Click a start, then an end (clicking earlier swaps them); hovering previews the band. The footer stages the pick: Clear empties it, Cancel reverts, Apply commits. Colours are neutral unless wrapped in a data-color region (shown here in primary). Stacks to one column when cramped.

Component

Uncontrolled via defaultStart/defaultEnd. Picks stage into the footer; onChange fires on Apply with { start, end } (ISO dates), and onApply/onCancel fire alongside.

JavaScript

From app.js. Renders both months, tracks start/end (swapping when the second pick is earlier), previews on hover, and stages the footer: Clear empties, Cancel reverts, Apply writes data-range-target-start/-end and closes the popover.
