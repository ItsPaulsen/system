Popover

A floating surface anchored to a trigger.

Default

The foundation under Dropdown Menu: the native Popover API for top-layer rendering, light-dismiss, and Esc, positioned with CSS anchor positioning. No JavaScript; the popovertarget button drives it. Use --panel for content padding and --center to center it on the trigger.

Keyboard shortcuts

Anchored below the trigger, flipping above when there's no room. Click outside or press Esc to dismiss.

Markup

<button popovertarget="popover-x">Open popover</button>
<div class="popover popover--panel popover--center" id="popover-x" popover>
  …
</div>
