Item

A row of media, content, and actions. For a standalone surface, use Card.

Default

Link rows on an elevated surface: item__media + item__content (title and description) + a trailing chevron in item__actions.

Getting started Set up your workspace in a few steps Documentation Guides and the full API reference

Grouped list

Wrap rows in item-group and put item-separator between them: the group is one surface, hairlines divide the rows.

Muted

item--muted just swaps the surface for a muted fill, for secondary content. It's independent of interactivity: put it on an <a>/<button> to make it clickable, or a <div> (as here) for a static row.

4 members Everyone with access to this workspace

Component

Slots as compound parts. Item renders an <a> with href, a <button> with onClick, else a <div>. Variant: muted.

Component

An interactive row is an <a> or <button> with class="item"; the slots are plain spans. 

<a class="item" href="…">
  <span class="item__media">…icon…</span>
  <span class="item__content">
    <span class="item__title">Getting started</span>
    <span class="item__description">Set up your workspace</span>
  </span>
  <span class="item__actions">…chevron…</span>
</a>
