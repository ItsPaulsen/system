Checkbox

A multi-select control. Any number of options can be on at once.

Default

Native <input type="checkbox">: works with forms and screen readers. The tick strokes itself on.

Disabled

Component

Props pass through to the native input (checked, defaultChecked, disabled, onChange); children are the label.
