Date Picker

A trigger that opens a calendar to pick a single date.

Default

A Calendar inside a Popover, with data-cal-target pointed at the trigger's label. Picking a day fills the label and closes the popover.

Component

The picker is Calendar in a Popover; onSelect (ISO date) updates the trigger label and closes it. Capped at 31 Dec of the current year.

Component

<!-- Trigger with a label span the calendar writes into. -->
<button class="button button--secondary" popovertarget="date-popover">
  <span data-dp-label>Pick a date</span>
</button>
<div class="popover popover--calendar" id="date-popover" popover>
  <div class="calendar" data-calendar data-cal-target="[data-dp-label]">…</div>
</div>

JavaScript

From app.js. Same initCalendars as Calendar; data-cal-target makes it a picker (writes the label, closes the popover on pick).
