Radio Group

A single-select group — options share a name, so exactly one is chosen.

Default

Native <input type="radio"> — the shared name handles mutual exclusion, no JavaScript needed.

Disabled

A single option can be disabled while the rest stay selectable.

Markup

<div class="radio-group" role="radiogroup">
  <label class="radio">
    <input type="radio" name="density" class="radio__input" />
    <span class="radio__label">Comfortable</span>
  </label>
  <!-- …more options with the same name -->
</div>
