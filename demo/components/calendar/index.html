Calendar

A month grid for choosing a date.

Default

Today is ringed, the chosen day is filled. Navigate with the arrows or, once a day has focus, the keyboard (arrows, Home, End, Page Up, Page Down).

Date picker

Put the calendar in a Popover and point data-cal-target at the trigger's label. Picking a day fills the label and closes the popover.

Component

Uncontrolled via defaultValue, or pass value + onSelect (both ISO dates) to control it. Capped at 31 Dec of the current year.

Component

<div class="calendar" data-calendar data-cal-value="2026-08-12">
  <div class="calendar__head">
    <button class="calendar__nav" data-cal-prev>…</button>
    <div class="calendar__period">
      <span class="calendar__select"><select data-cal-month></select></span>
      <span class="calendar__select"><select data-cal-year></select></span>
    </div>
    <button class="calendar__nav" data-cal-next>…</button>
  </div>
  <div class="calendar__weekdays"></div>
  <div class="calendar__days" data-cal-days></div>
</div>

<!-- Date picker: same calendar inside a Popover, plus
     data-cal-target="#label" on the .calendar. -->

JavaScript

From app.js. Builds the grid from data-cal-value, wires the month/year selects, arrows, and keyboard, and writes back to data-cal-target on pick.
