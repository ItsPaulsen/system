Sheet

A panel that slides in from a screen edge.

Default

Built on native <dialog>, so the focus trap, Esc-to-close, and inert background come for free. --left slides it from the opposite edge. Click the backdrop, Esc, or the close button to dismiss.

Filters

A sheet holds a focused, secondary task beside the page (filters, details, a quick form) without a full navigation.

Navigation

Slides from the inline-start edge, handy for a menu drawer.

Component

Compound parts over native <dialog>. side="left" flips the edge; the dialog owns the focus trap and dismissal.

Component

<button data-dialog-open="demo-sheet">Open</button>

<dialog class="sheet" id="demo-sheet">
  <div class="sheet__inner">
    <header class="sheet__header">
      <h2 class="sheet__title">Filters</h2>
      <button class="sheet__close" data-dialog-close aria-label="Close">…</button>
    </header>
    <div class="sheet__body">…</div>
  </div>
</dialog>

<!-- Variant: --left -->

JavaScript

From app.js. Shared with Dialog: one delegated listener opens [data-dialog-open], closes on the button, backdrop, and Esc, locks body scroll, and names each modal from its title (aria-labelledby) for screen readers.
