Carousel

A swipeable row of items, one or more in view.

Default

One item per view. A control disables itself at each end; the live region announces the current slide. Needs initCarousel().

Multiple items

Set --carousel-cols to show more than one at a time, usually per breakpoint (2 on phones, 3 on desktop here). --carousel-gap sets the space between.

Component

items are the slide nodes; cols and gap drive the CSS custom props. Prev/next, arrow keys, the disabled ends and the live count are built in.

Component

initCarousel() translates the track: pointer drag (mouse and touch) with a rubber-band past the ends, snap-to-item on release, plus the buttons, arrow keys, and the "Slide N of M" region. 

<div class="carousel" data-carousel role="group" aria-roledescription="carousel" aria-label="Highlights">
  <button class="carousel__control carousel__control--prev" aria-label="Previous slide">…</button>
  <div class="carousel__viewport">
    <ul class="carousel__track">
      <li class="carousel__item" role="group" aria-roledescription="slide">…</li>
      <!-- …more slides -->
    </ul>
  </div>
  <button class="carousel__control carousel__control--next" aria-label="Next slide">…</button>
  <span class="sr-only" aria-live="polite" data-carousel-status></span>
</div>

/* Show more than one at a time by overriding the col count, per breakpoint: */
.carousel { --carousel-cols: 3; }
