Toggle group

A single choice from a few options, styled as a segmented track. For content panels, use Tabs.

Default

Radios share a name, which makes them mutually exclusive. No JS.

With icons

Put an icon before toggle-group__label. toggle-group--pill fully rounds the track.

Disabled

Component

items drive the segments; pill rounds the track. Uncontrolled via defaultValue, or pass value + onChange.

Component

<div class="toggle-group" role="radiogroup" aria-label="View">
  <input type="radio" name="group" id="t1" class="toggle-group__radio" checked />
  <label class="toggle-group__tab" for="t1"><span class="toggle-group__label">Overview</span></label>
  <input type="radio" name="group" id="t2" class="toggle-group__radio" />
  <label class="toggle-group__tab" for="t2"><span class="toggle-group__label">Details</span></label>
</div>
