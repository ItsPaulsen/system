Spinner

An indeterminate loading indicator.

Sizes

Use when work is in progress but has no measurable completion; reach for Progress when it does.

On a color

The arc is currentColor, so it inherits the surrounding text color. Inside an already-labelled control, silence it (label={null} in React, or aria-hidden in HTML) so the label isn't announced twice.

Component

size is sm or lg; label names it for assistive tech.

Component

<span class="spinner" role="status" aria-label="Loading"></span>
