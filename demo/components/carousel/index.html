Carousel

A swipeable row of items, one or more in view.

Default

One item per view. A control disables itself at each end; the live region announces the current slide. Needs initCarousel().

Jump to a slide

Any element inside the root with data-carousel-goto="<index>" goes to that slide, and carries aria-current="true" while it's the current one, so the styling hangs off state rather than a class you maintain. Dots here; a rail of thumbnails is the same hook with a picture in the button. In React it's the nav prop, which hands you the count, the current index and a way to jump, because there the state is already yours to read.

Multiple items

Set --carousel-cols to show more than one at a time, usually per breakpoint (2 on phones, 3 on desktop here). --carousel-gap sets the space between, and --carousel-slide the settle's timing, which the JS reads off the root.

Component

items are the slide nodes; cols and gap drive the CSS custom props, and nav renders a rail or dots off the current index. Prev/next, arrow keys, the disabled ends and the live count are built in.

Component

initCarousel() runs one of two engines on the same markup. On a pointer it translates the track and owns the drag, with a rubber band past the ends; under a finger the viewport is a native scroll container with snap points, so the swipe is the platform's own momentum rather than an imitation of it. Either way the buttons, arrow keys, ends and "Slide N of M" behave the same, and the set has a first and a last: there is no wrap. A release commits on 30% of the viewport at any speed, or on a flick, which has to travel 24px and end inside 500ms. Slides can be hidden; fire carousel:refresh on the root after showing or hiding them. 

<div class="carousel" data-carousel role="group" aria-roledescription="carousel" aria-label="Highlights">
  <button class="carousel__control carousel__control--prev" aria-label="Previous slide">…</button>
  <div class="carousel__viewport">
    <ul class="carousel__track">
      <li class="carousel__item" role="group" aria-roledescription="slide">…</li>
      <!-- …more slides -->
    </ul>
  </div>
  <button class="carousel__control carousel__control--next" aria-label="Next slide">…</button>
  <span class="sr-only" aria-live="polite" data-carousel-status></span>
</div>

/* Show more than one at a time by overriding the col count, per breakpoint: */
.carousel { --carousel-cols: 3; }
