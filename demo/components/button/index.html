Button

Four skins driven by a global density knob. Set data-size="sm|md|lg" on any ancestor and the button (and any other density-driven component inside) rescales — no per-button size modifier.

Size

Same button, three densities via data-size on a wrapping element.

Primary

Filled with the brand primary.

Secondary

Soft primary tint background, primary text.

Flat

Transparent surface; primary text; fills on hover.

Destructive

Soft danger tint background, danger text.

Icon-only

Square, no inline padding — always pair with aria-label.

With icon

Icon lands before or after the label; add button--with-start-icon or button--with-end-icon to tighten padding on the icon side.

Disabled

Filled skins drop to fill-quaternary; flat stays transparent. Text and icon go to fill-secondary. Cursor is not-allowed, hover does nothing.

Markup

<button type="button" class="button button--primary">Continue</button>

<!-- Skins:   --primary --secondary --flat --destructive -->
<!-- Layout:  --icon  --with-start-icon  --with-end-icon -->
<!-- Density: data-size="sm|md|lg" on any ancestor -->

<button type="button"
        class="button button--secondary button--with-start-icon">
  <svg>…</svg>Add item
</button>

<button type="button"
        class="button button--primary button--icon"
        aria-label="Open">
  <svg>…</svg>
</button>
