Tabs

Layered sections of content; one panel shown at a time. For a plain single choice with no panels, use Toggle group.

Default

Arrow keys move between tabs and switch the panel; the panel is a tab stop so keyboard users reach its content. Needs initTabs().

Component

items carry each tab's label and panel. Uncontrolled via defaultValue, or pass value + onChange. Arrow-key nav and roving focus are built in.

Component

The markup carries every ARIA attribute; initTabs() only wires the keyboard and panel toggling. 

<div class="tabs">
  <div class="tabs__list" role="tablist" aria-label="Project">
    <button class="tabs__tab" role="tab" id="t1" aria-controls="p1" aria-selected="true" >
      <span class="tabs__label">Overview</span></button>
    <!-- …more tabs -->
  </div>
  <div class="tabs__panel" role="tabpanel" id="p1" aria-labelledby="t1" tabindex="0">…</div>
  <!-- …more panels, hidden on the rest -->
</div>
