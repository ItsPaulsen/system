Data table

Add data-table and the behaviour is layered on (see JavaScript below); with no JS it stays a plain table. Sortable columns are a th aria-sort="none" holding a .table__sort button (add data-type="number" for numeric sort). A .table__select column with a header Checkbox selects every row; for empty or loading states drop an Empty block or Skeleton rows in the tbody.

Component

Wraps the table in .table-wrap for you; pass the usual thead/tbody as children.

Component

<div class="table-wrap">
  <table class="table">
    <thead><tr><th scope="col">Name</th>…</tr></thead>
    <tbody><tr><td>Ada Berg</td>…</tr></tbody>
  </table>
</div>

JavaScript

From app.js. Makes .table-wrap a focusable scroll region (role="region" + tabindex + label) only while it overflows, so tables that fit get no stray tab stop. React uses a ResizeObserver.

JavaScript (data table)

From app.js. Wires data-table: sortable headers reorder the tbody and toggle aria-sort; the header checkbox drives row selection and reflects all/some/none as checked/indeterminate.
