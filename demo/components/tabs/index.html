Tabs

Layered sections of content; only one visible at a time.

Default

Radios share a name, which makes them mutually exclusive. No JS.

With icons

Put an icon before tabs__label. tabs--pill fully rounds the track.

Disabled

Component

items drive the tabs; pill rounds the track. Uncontrolled via defaultValue, or pass value + onChange.

Component

<div class="tabs" role="tablist">
  <input type="radio" name="group" id="t1" class="tabs__radio" checked />
  <label class="tabs__tab" for="t1"><span class="tabs__label">Overview</span></label>
  <input type="radio" name="group" id="t2" class="tabs__radio" />
  <label class="tabs__tab" for="t2"><span class="tabs__label">Details</span></label>
</div>
