Dropdown Menu

A button that opens a floating list of actions.

Default

A menu of actions, not a value picker. Reach for Select when you need a single choice back.

With icons

A leading menu__item-icon gives each action a glyph.

Markup

<div class="menu">
  <button class="menu__trigger" popovertarget="menu-x" aria-haspopup="menu" aria-expanded="false">
    Options <svg class="menu__chevron" …>…</svg>
  </button>
  <div class="menu__list popover" id="menu-x" popover role="menu">
    <button class="menu__item" role="menuitem" tabindex="-1">
      Edit<span class="menu__shortcut">⌘E</span>
    </button>
    <hr class="menu__separator" />
    <button class="menu__item menu__item--danger" role="menuitem" tabindex="-1">Delete</button>
  </div>
</div>
