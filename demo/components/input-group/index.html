Input Group

A field with an icon, text, or button attached.

Icon

An SVG in the input__leading (or input__trailing) slot. The slot shares the field's focus ring, and the icon is decorative (aria-hidden), so the label names the field. --rounded gives the pill search field.

Text

Short text add-ons: a unit, prefix, or suffix (e.g. $, USD). Both slots can be used at once.

Button

Bind the label with for/id, not by wrapping: the group holds two controls. Drop a button--flat Button (data-size="sm") in a slot for an inline copy or clear action.

Component

Input Group is the Input component with leading/trailing slots. Interactive add-ons (a Button) compose in the markup, as above.

Component

<span class="input__container">
  <span class="input__leading"><svg …>…</svg></span>
  <input class="input__element" type="text" />
  <span class="input__trailing" data-size="sm">
    <button class="button button--flat">Copy</button>
  </span>
</span>
