Error Summary

After a failed submit, list every error at the top of the form and link each one to its field.

Default

A labelled region with a link per error. Insert it after a failed submit and call .focus() on it (tabindex="-1") so it is announced.

There is a problem

  • Enter a valid email address
  • Enter your full name

In a form

The fields stack above one another; each summary link jumps to and focuses its field.

There is a problem

  • Enter your full name
  • Enter a valid email address

Component

errors are { id, message }, where id matches the field's id. Mount it with the current list: it renders nothing while empty and focuses itself the moment errors appear.

Component

initErrorSummary() makes each link focus its field, not just scroll to it. 

<div class="error-summary" tabindex="-1" aria-labelledby="es-h">
  <p class="error-summary__title" id="es-h">There is a problem</p>
  <ul class="error-summary__list">
    <li><a class="error-summary__link" href="#es-email">Enter a valid email address</a></li>
  </ul>
</div>
