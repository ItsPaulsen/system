Progress

A bar showing how far a task has advanced.

Determinate

Use when completion is measurable (upload, import, multi-step form): set value and max on the native <progress>, which reports them to assistive tech. When you can't measure progress, use Spinner instead.

Component

A thin wrapper over native <progress>; value, max, and aria-label pass straight through.

Component

<progress class="progress" value="70" max="100"
          aria-label="Upload"></progress>
