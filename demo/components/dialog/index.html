Dialog

A focused overlay that interrupts the page.

Default

Native <dialog> handles the focus trap, Esc-to-close, and an inert background. data-dirty-guard on the form keeps Save disabled until a field changes and reverts everything on close, app-level UX kept out of the component.

Edit project

Update the project name and visibility.

Destructive

A confirm dialog takes role="alertdialog" and an aria-describedby pointing at the consequence, so assistive tech announces the warning, not just the title.

Delete project?

This permanently deletes the project and everything in it. You can't undo this.

Component

Compound components over the native <dialog>, no extra dependencies. showModal() gives the focus trap and inert backdrop for free.

Component

<button data-dialog-open="demo-dialog">Open dialog</button>

<dialog class="dialog" id="demo-dialog">
  <div class="dialog__inner">
    <h2 class="dialog__title">Delete project?</h2>
    <p class="dialog__text">…</p>
    <div class="dialog__actions">
      <button class="button button--secondary" data-dialog-close>Cancel</button>
    </div>
  </div>
</dialog>

JavaScript

From app.js. One delegated listener opens [data-dialog-open], closes [data-dialog-close] and backdrop clicks, and locks body scroll. It also names each modal from its title (aria-labelledby) so screen readers announce more than "dialog". Shared with Sheet.

JavaScript

Optional dirty guard. Add data-dirty-guard to any form and its submit stays disabled until a field differs from its default, then reverts on the dialog's close. The submit can live outside the form (associated via form=).
