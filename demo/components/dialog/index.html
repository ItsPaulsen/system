Dialog

A focused overlay that interrupts the page.

Default

Native <dialog> handles the focus trap, Esc-to-close, and an inert background. Click the backdrop or a button to dismiss.

Delete project?

This permanently deletes the project and everything in it. You can't undo this.

Markup

<button data-dialog-open="demo-dialog">Open dialog</button>

<dialog class="dialog" id="demo-dialog">
  <div class="dialog__inner">
    <h2 class="dialog__title">Delete project?</h2>
    <p class="dialog__text">…</p>
    <div class="dialog__actions">
      <button class="button button--flat" data-dialog-close>Cancel</button>
    </div>
  </div>
</dialog>
