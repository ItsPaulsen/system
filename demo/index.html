      How to use

      Drop in one globals.css (reset, focus ring, and all tokens), then reference with var(--…). Add a component's CSS as you need it. 

      @import url("globals.css");

.card {
  background: var(--background-primary);
  border-radius: var(--radius-md);
  box-shadow: var(--shadow-sm);
  padding: var(--space-24);
}
