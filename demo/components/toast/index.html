Toast

A brief message that appears, then fades on its own.

Types

A default message, the semantic types, and a promise that resolves loading to done. removed is the counterpart to success: something was taken away and it worked, so the glyph stays at the text's own weight rather than going red.

Component

Mount <Toaster /> once near the root, then call toast() (or toast.success/error/removed/promise) from anywhere.

Component

No markup to author: the helper mounts the pill itself. The shell exposes it via a data-toast trigger; in your own code call toast with a message. 

<button data-toast="Changes saved">Show toast</button>

toast("Changes saved");

JavaScript

From app.js. Mounts one reused pill plus the two live regions, picks the icon for the type, and clears the previous timer so a second message replaces the first.
