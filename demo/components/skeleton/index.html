Skeleton

A placeholder that holds a content's shape while it loads.

Shapes

One class, three shapes: default is a rounded rectangle, --circle an avatar, --text a line of text. Set width/height to match the real content so the layout doesn't shift on swap.

Text

Stack --text lines and trim the last with width to stand in for a paragraph. Wrap the loading region in role="status" and aria-busy="true" so assistive tech announces the wait; repeat that on any skeleton group.

Card

List

Table

Component

One Skeleton with a variant; compose several for cards, lists, and tables. Size each with style. Mark the region, not each shape.

Component

<!-- Shapes: default block · --circle · --text -->
<div class="skeleton" style="width: 8rem; height: 5rem"></div>
<div class="skeleton skeleton--circle" style="width: 3rem"></div>
<div class="skeleton skeleton--text"></div>

<!-- Mark the region, not the shapes, for assistive tech -->
<div role="status" aria-busy="true" aria-label="Loading profile">
  <div class="skeleton skeleton--circle" style="width: 3rem"></div>
  <div class="skeleton skeleton--text"></div>
</div>
