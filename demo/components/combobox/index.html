Combobox

A text field that filters a list as you type.

Default

Built from the Input shell and the Select popup. Type to filter; nothing is preselected, so Arrow keys move into the matches and Enter picks the highlighted one (Enter with none highlighted just closes). Reach for Select when the list is short enough to scan.
