Number Field

A number input with −/+ steppers.

Default

Compact 32px size. Click a stepper (press and hold to repeat) or type a value. Arrow Up/Down step it too. Needs initNumberFields().

Large

number-field--lg: 48px with body-medium text. The value cell holds two digits, then grows from the third.

Bounded

Bounds (min/max/step) disable a stepper at its edge and clamp a typed value on blur.

Component

Uncontrolled via defaultValue, or pass value + onChange. min/max/step bound and quantise it; stepping and clamping are built in.

Component

Reuses the Input field markup; data-number-field wires the steppers, and the bounds go in data-min/data-max/data-step on the <input> (min/max/step aren't valid on a text input). 

<div class="input number-field" data-number-field>
  <label class="input__label" for="qty">Quantity</label>
  <span class="input__container number-field__control">
    <button class="number-field__step" type="button" data-step="-1" aria-label="Decrease">−</button>
    <input class="input__element number-field__input" id="qty" type="text" inputmode="numeric"
           value="1" data-min="0" data-max="999" data-step="1" />
    <button class="number-field__step" type="button" data-step="1" aria-label="Increase">+</button>
  </span>
</div>
