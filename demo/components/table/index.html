Component

Wraps the table in .table-wrap for you; pass the usual thead/tbody as children.

Component

<div class="table-wrap">
  <table class="table">
    <thead><tr><th scope="col">Name</th>…</tr></thead>
    <tbody><tr><td>Ada Berg</td>…</tr></tbody>
  </table>
</div>

JavaScript

From app.js. Only while a .table-wrap actually overflows does it become a focusable scroll region (role="region" + tabindex + label), so keyboard users can pan a wide table without a stray tab stop on ones that fit. The React Table does the same with a ResizeObserver.
