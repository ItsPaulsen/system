Accordion

Collapsible sections that expand one panel at a time.

Default

Native <details> — open/close works without JavaScript.

How do I get started?

Import the tokens, then reference them with var(--…).

Can I change the colours?

Swap the anchor values in tokens.css and everything retints.

Does it support dark mode?

Yes — set data-theme="dark" on the root.

Markup

<div class="accordion">
  <details class="accordion__item">
    <summary class="accordion__summary">
      Question
      <span class="accordion__toggle">…</span>
    </summary>
    <div class="accordion__body"><p>Answer.</p></div>
  </details>
</div>
