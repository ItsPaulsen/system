Input

A single-line text field.

Default

Rounded

Filled

File

type="file": the whole field is the click target, so the native ::file-selector-button is plain text (no surface), not a button. For icons, text, or a button beside the field, see Input Group.

Disabled

Required

The * is decorative: the required attribute does the validation.

Helper text

input__hint below the field; wire it with aria-describedby so it's announced with the input.

Invalid

--invalid lands on .input__container (not the <input>), paired with an input__error message and aria-invalid on the field.

Component

label, hint, and error render their slots; fill, rounded, and invalid are the container modifiers. Other props pass through to the input.

Component

<label class="input">
  <span class="input__label">Email</span>
  <span class="input__container">
    <input class="input__element" type="email" aria-describedby="hint" />
  </span>
  <span class="input__hint" id="hint">Helper text</span>
</label>

<!-- Modifiers on .input__container:  --fill  --rounded  --invalid
     Below the field:  .input__hint (helper)  ·  .input__error (invalid) -->
