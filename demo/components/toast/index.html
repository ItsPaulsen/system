Toast

A brief message that appears, then fades on its own.

Types

A default message, the semantic types, and a promise that resolves loading to done.

Component

Mount <Toaster /> once near the root, then call toast() (or toast.success/error/promise) from anywhere.

Usage

The shell exposes it via a data-toast trigger; in your own code call the toast helper with a message. 

<button data-toast="Changes saved">Show toast</button>

toast("Changes saved");
