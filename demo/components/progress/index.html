Progress

A bar showing how far a task has advanced.

Determinate

Use when completion is measurable (upload, import, multi-step form): set value and max on the native <progress>, which reports them to assistive tech. When you can't measure progress, use Spinner instead.

Component

A thin wrapper over native <progress>; value, max, and aria-label pass straight through.

Component

<progress class="progress" value="70" max="100"
          aria-label="Upload"></progress>

Steps

Progress through a fixed, ordered flow. It's an <ol>, so the sequence is announced; mark the active step aria-current="step" and finished steps .is-done (which swaps the number for a check). Colours ride --accent, so a data-color region retints it.

  1. 1 Account
  2. 2 Profile
  3. 3 Preferences
  4. 4 Done

Steps component

Pass the labels and the active index (0-based); earlier steps render done, the active one current, later ones plain.

Steps markup

<ol class="steps">
  <li class="steps__step is-done">
    <span class="steps__indicator"><span class="steps__num">1</span></span>
    <span class="steps__label">Account</span>
  </li>
  <li class="steps__step is-current" aria-current="step">…</li>
  <li class="steps__step">…</li>
</ol>
