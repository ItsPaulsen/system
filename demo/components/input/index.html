Input

A single-line text field.

Default

Rounded

Filled

Leading & trailing

Slots accept an SVG or short text (e.g. $, USD).

Disabled

Invalid

Modifier lands on .input__container, not the <input>.

Required

The * is decorative — the required attribute does the validation.

Markup

<label class="input">
  <span class="input__label">Email</span>
  <span class="input__container">
    <span class="input__leading">@</span>
    <input class="input__element" type="email" />
  </span>
</label>
