Slider

Pick a value from a range by dragging.

Default

A native <input type="range">. Keyboard (arrows, Home, End), steps, and min/max are all built in. The slider-field wrapper adds a label and a live value.

50

Usage

React: how you drop it into a page.

step snaps the thumb to fixed increments.

Markup

<div class="slider-field">
  <div class="slider-field__header">
    <label class="slider-field__label" for="volume">Volume</label>
    <output class="slider-field__value" for="volume">50</output>
  </div>
  <input class="slider" type="range" id="volume" min="0" max="100" value="50" />
</div>

CSS

From components.css. Also load globals.css (tokens + baseline).

JavaScript

From app.js. Sets the fill width from the value and updates the <output>. Call once on load; re-run after adding sliders dynamically.

React

A <Slider> that tracks the fill with React state (controlled or uncontrolled). Same .slider classes; no extra styling.
