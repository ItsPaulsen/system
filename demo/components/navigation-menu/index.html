Navigation Menu

A row of links for moving between top-level destinations.

Default

Each item is a link to another page; the current one carries aria-current="page".

  • Overview
  • Projects
  • Reports
  • Settings

With dropdown

Give an item a .nav-menu__menu panel and it opens on hover or keyboard focus; Esc closes it. The top-level link stays clickable (no chevron) and advertises its panel to screen readers; items without a panel stay plain.

  • Overview
    Dashboard Activity Notifications
  • Projects
    All projects Starred Archived Templates
  • Reports
  • Settings

Component

Compound parts. Add a NavMenuPanel inside an item for a dropdown; current marks the active link. The reveal is CSS; the parts wire the aria-expanded/haspopup and Esc-to-close.

Component

<nav class="nav-menu" aria-label="Main">
  <ul class="nav-menu__list">
    <li class="nav-menu__item">
      <a class="nav-menu__link" href="#" aria-current="page">Overview</a>
      <div class="nav-menu__menu">
        <a class="nav-menu__menu-link" href="#">Dashboard</a>
        <a class="nav-menu__menu-link" href="#">Activity</a>
      </div>
    </li>
    <li class="nav-menu__item"><a class="nav-menu__link" href="#">Reports</a></li>
  </ul>
</nav>

JavaScript

From app.js. The panel reveals in CSS; this only annotates a panel-owning trigger (aria-haspopup/aria-controls/aria-expanded) and adds Esc-to-close, so a dropdown parent announces and dismisses like a menu while staying a real link. The React parts do the same internally.
